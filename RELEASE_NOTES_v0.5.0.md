# BulkFormer skeletal-muscle aging benchmark reproducibility archive v0.5.0

This release contains the canonical reviewer and reproducibility archive for the study-held-out BulkFormer skeletal-muscle age-prediction benchmark.

Primary result:

- 8 studies and 267 participant representatives;
- primary pretrained mean-study MAE: 25.335 years;
- conventional Elastic Net comparator: 7.716 years;
- paired difference: +17.619 years;
- favorable held-out studies: 0/8.

Release asset:

- `BulkFormer_Aging_Reviewer_Package_v0.5_2026-07-21.zip`
- 22,873,076 bytes
- 244 manifest-tracked files
- SHA-256: `e55860f6f8a94df63069a2825b15cae9600f67a5636c7bba6708bdd1b4b26b10`

The archive supports clean-room recomputation from frozen features. It does not include the BulkFormer checkpoint, graph files, raw FASTQ/SRA data, all upstream expression matrices, credentials or private participant data. End-to-end feature extraction is outside the archive scope.
